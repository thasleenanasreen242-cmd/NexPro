# NexPro

A premium, responsive electronics storefront built with Next.js and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Product names, prices, ratings, and promotional offers are demonstration content only.
- Cart, wishlist, product search, and category filters are front-end demo interactions.
- No payment gateway, inventory system, or newsletter provider is connected yet.
- Replace demonstration product data and customer policies with verified business information before launch.
